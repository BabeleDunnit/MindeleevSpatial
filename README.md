# MendeleevSpatial

info su contenuti dei branch:

feature/polyhedra: esperimenti vari con orbite di Lissajoux e generazione di poliedri (solidi platonici) colorati. Coordinate hardcoded, non riesco a fare flat shading. 0 per generare tanti poliedri fermi, spazio per generarne uno che si muove. Classica struttura Polytron e PolytronManager, quest'ultimo script attaccato a un cubo statico che fa da nucleo.
